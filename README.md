# Baxter's *Christian Directory* — Original and Modernized

Richard Baxter's *A Christian Directory, or, A Summ of Practical Theologie and
Cases of Conscience* (1673) is a landmark of Puritan pastoral theology, and
a frequent reference in biblical counseling. This repo holds:

1. **`original/`** — the unaltered public-domain text, as transcribed by
   Project Gutenberg from the 1846 Virtue edition of *The Practical Works of
   Richard Baxter*.
2. **`modernized/`** — a work-in-progress rendering into modern English,
   done passage by passage.
3. **`STYLE_GUIDE.md`** — the rules the modernization follows, so the
   result stays consistent.
