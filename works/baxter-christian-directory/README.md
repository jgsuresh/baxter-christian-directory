# Richard Baxter, *A Christian Directory* (1673)

*A Christian Directory, or, A Sum of Practical Theology and Cases of
Conscience* is a landmark of Puritan pastoral theology and a frequent
reference in biblical counseling: hundreds of numbered Directions for the
whole Christian life.

Web page and EPUB: <https://jgsuresh.github.io/texts/baxter-christian-directory/>
