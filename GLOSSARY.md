# Glossary

Standing word decisions, shared by every work in this repository so that the
same old word gets the same modern rendering everywhere. Writers use these
instead of choosing afresh, and record any new decision in the translator's
notes; recurring ones are added here between rounds. Entries were gathered
from Baxter's *Christian Directory*, Part 1, where most decisions were first
made (the counts there show how often each came up).

"Kept" means the word stays in the modernized text, with a note at its first
use in a file. "By context" means read the sentence: the entry lists the
usual renderings.

## Words whose meaning has shifted

These look familiar but meant something different (or broader) in the 1600s.
They are the main risk.

| Old word | What it meant | Our rendering |
|---|---|---|
| **affections** | Emotions and desires: love, fear, joy, anger. | Kept (a technical term). |
| **amiable** | Worthy of love. | *lovable* |
| **apprehension(s)** | Understanding, grasp of something. | *understanding* |
| **bravery** | Finery, showy dress. | *finery* |
| **carnal** | Unspiritual; ruled by the flesh. | Kept. |
| **comfortable** | Comforting, strengthening. | *comforting* |
| **conceit(s)** | Notion, idea, fancy (not vanity). | *notion(s)* |
| **conference** | Conversation, discussion. | *conversation*, *discussion* |
| **conversation** | Conduct, way of life. | *conduct*, *way of life* (when he means behavior) |
| **converse** (noun) | Dealings, association. | *dealings*, *association* |
| **convince** | Prove wrong, or persuade. | By context: *prove wrong*, *show*; kept when it means persuade. |
| **covetous(ness)** | Love of money and possessions. | *greedy*, *greed* |
| **crosses** | Trials, hardships. | *hardships* |
| **curious, curiosity** | Elaborate; over-subtle, fussy (not inquisitive). | By context: *elaborate*, *intricate*, *over-subtle* |
| **delight** | Settled, deep gladness in something. | Kept. |
| **discourse** | Talk. | *talk*, *conversation* |
| **divines** | Theologians, ministers. | *theologians* (or *ministers*) |
| **effectual** | Effective. | *effective* |
| **entertain** | Receive, welcome. | *receive*, *welcome* |
| **faction** | Divisiveness, party spirit. | *divisiveness* |
| **fantasy** | Imagination. | *imagination* |
| **felicity** | Happiness. | *happiness* |
| **flesh, fleshly** | The sinful or worldly side of human appetites (Paul's "flesh vs. Spirit"). | Kept. |
| **habit (of body)** | Bodily constitution. | *bodily constitution* |
| **happy** | Blessed. | *blessed* (by context) |
| **hardly** | With difficulty; harshly. | By context. |
| **humour** | Mood, whim; a bodily humor. | By context: *mood*, *whim*; keep *humors* for the medical sense, with a note. |
| **impudent** | Shameless. | *shameless* |
| **inordinate** | Excessive, disordered. | *excessive* (or keep in "inordinate love") |
| **like** | Likely. | *likely* |
| **meat** | Food in general. | *food*, *meals* |
| **melancholy** | A lasting low, fearful, or brooding state, thought partly bodily. Not quite modern depression. | Kept. |
| **painful** | Painstaking, diligent. | *painstaking*, *diligent* |
| **parts** | Natural abilities, gifts. | *abilities*, *gifts* |
| **passionate** | Swayed by strong feeling. | *emotional* |
| **physic** | Medicine. | *medicine* |
| **preferment** | Advancement, promotion. | *advancement* |
| **presently** | At once. | *at once* |
| **pretend, pretence** | Claim; pretext. | *claim*, *pretext* |
| **prevent** | Go before, anticipate. | Usually *go before*; by context. |
| **religion** | Worship and devotion, practiced piety. | Kept; note if it could mislead. |
| **sad** | Serious, grave; grievous. | By context: *serious*, *grim*, *a sorry thing* |
| **security, secure** | Careless confidence. | *careless confidence*, *carelessly confident* (or kept, with a note) |
| **sensible (of)** | Aware (of); felt. | *aware (of)* |
| **sensitive** (appetite, faculties) | Of the senses. | *sensory* |
| **sensual, sensuality** | Of the senses and bodily appetites generally, not only sexual. | *physical*, *pleasure-loving*; *indulgence in physical pleasure* |
| **sensualists** | | *pleasure-seekers* |
| **several** | Separate, respective. | *respective*, *separate*, *various* |
| **sports** | Amusements, pastimes. | *amusements* |
| **still** | Always, continually. | *always*, *continually* |
| **suffer** | Allow. | *allow* |
| **vain, vanity** | Empty, worthless (not conceited). | *empty*, *worthless*; *empty pursuits* |
| **want** | Lack. | *lack* |

## Old forms and words with a plain modern equivalent

| Old | Modern |
|---|---|
| thou, thee, thy, thine; -est, -eth | you, your; plain verb forms |
| hath, doth, saith | has, does, says |
| unto | to (the fixed phrase "repentance unto life" is kept) |
| whither, thither, thence | where, there, from there |
| yea, nay (as intensifiers) | indeed |
| methinks | I think, it seems to me |
| must needs | must necessarily |
| fain | gladly |
| anon | later, shortly |
| oft | often |
| loth | reluctant (or *loath*) |
| forbear | refrain (from), go without |
| endeavour | effort, try |
| concernment | concern |
| beseeming | fitting |
| take heed | take care, be careful |
| raiment | clothing |
| threatenings | threats |
| estimation | esteem |
| rectitude | uprightness |
| obloquy | reproach, scorn |
| gamesters | gamblers |
| gallants | fashionable gentlemen |
| concoction (of food) | digestion |
| infidel | unbeliever |
| Holy Ghost | Holy Spirit |
| &c. | etc. |
| wilful, honour, Saviour, endeavour | willful, honor, Savior, endeavor (American spelling) |
| scarce (adverb) | scarcely |
| prevailing, prevalent | powerful, successful |

## Kept on purpose

Theological and technical terms stay, with a note at first use in a file
where a modern reader could mistake them: justification, sanctification,
regeneration, covenant, grace, mortify, carnal, affections, flesh,
melancholy, cases of conscience. Each work's `NOTES.md` lists that author's
own technical terms.
